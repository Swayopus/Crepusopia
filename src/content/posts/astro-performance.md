## 先确定测量条件

开发服务器包含调试与热更新代码，性能测试应使用正式构建。本文是一份检查示例，不代表已经测得的线上评分。

## 构建与预览

```powershell
npm.cmd run verify
npm.cmd run preview
```

## 网络资源

- 确认字体、头像和代码样式返回成功状态。
- 搜索索引应在打开搜索并输入关键词后加载。
- 一言接口失败时，页面仍然应该有可读的句子。

## 在真实设备上检查

测试窄屏导航、首次打开目录、切换主题和浏览器返回。单个分数不能代替这些实际操作。

## 检查记录

| 检查项 | 期望结果 |
| --- | --- |
| 首页 | 无缺失资源 |
| 搜索 | 新查询覆盖旧查询 |
| 目录 | 每个链接都定位到真实标题 |
| 字体 | 保持站点原有字体 |
